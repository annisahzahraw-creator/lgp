ATURAN LIGA GRAND PERMATA
Format ligaSetiap pemain tampil tepat 3 kali: satu pertandingan per putaran, dengan 3 partner berbeda.
PengacakanPartner dan lawan diacak sekali saat dibuat. Mengganti nama tidak mengacak ulang jadwal.
Skor gameDua game tetap sampai 15 tanpa deuce. Satu sisi harus 15, sisi lain 0 sampai 14.
Poin individuKedua pemain satu tim menerima selisih sama: (A game 1 - B game 1) + (A game 2 - B game 2).
Contoh15-10 dan 15-12 memberi +8; 13-15 dan 12-15 memberi -5; total sementara +3.
Hasil dihitungHanya pertandingan dengan empat skor lengkap dan sah masuk rekap. Skor parsial belum dihitung.
Urutan klasemenTotal selisih terbesar, lalu game menang terbanyak, lalu poin masuk terbanyak.
Jika masih seriPeringkat tetap sama. ID hanya mengurutkan tampilan, bukan penentu juara; sepakati tie-break bila perlu.
OperasionalLapangan belum ditetapkan. Dalam satu putaran pemain tidak tumpang tindih: hingga 6 laga bisa bersamaan.
Data perlu diisiNama asli 24 pemain, lapangan bila dipakai, dan skor. Nama awal adalah label sementara, bukan data peserta asli.
Kontrol skorPeriksa skor berarti hasil tidak sah. Jangan mengganti kolom rumus atau mengurutkan sebagian tabel input.
Batas jadwalJadwal untuk 24 slot tetap. Jika jumlah peserta berubah, jadwal perlu dibuat ulang.
